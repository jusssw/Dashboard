# Task Dashboard

A personal productivity dashboard for adding, completing, editing, and removing persistent tasks through a connected Supabase project.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required integration: Supabase connector named `supabase`

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `artifacts/task-dashboard/src/pages/home.tsx` — dashboard UI and task interactions
- `artifacts/api-server/src/routes/tasks.ts` — task and summary API routes
- `artifacts/api-server/src/lib/supabase.ts` — server-side Supabase proxy wrapper
- `lib/api-spec/openapi.yaml` — API contract source of truth
- `supabase/schema.sql` — one-time Supabase table and development policy setup

## Architecture decisions

- The frontend uses generated React Query hooks from the OpenAPI contract rather than calling Supabase directly.
- The API server talks to Supabase through the Replit connector proxy, keeping provider credentials out of application code.
- The first version is intentionally single-user; authentication and owner-scoped RLS should be added before sharing publicly.
- The task table uses text UUIDs generated by the API so inserts work without relying on a database-specific UUID default.

## Product

- View open, completed, due-today, and overall progress counts.
- Add tasks with optional context and due dates.
- Complete, edit, and delete tasks with persisted results.
- Filter the queue and view the next tasks in order.

## User preferences

- The user wants Supabase persistence for tasks and a foundation that can grow into notes, projects, and calendar features.

## Gotchas

- Run `supabase/schema.sql` once in the Supabase SQL Editor before using task CRUD.
- The app reports a setup-specific error when the `tasks` table is missing instead of silently using local state.
